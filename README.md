# 技能侦探 · Skill Detective

本插件由 CyberMind-labs 的 52yin14n9、Admie、Assomeity、George 联合开发。

给 DeepSeek Harness 用的自动技能管家：在对话里发现缺失的技能，检索候选，安装前做安全审查，安装后统一管理。

## 安装与开始使用

1. 在 DeepSeek Harness 的插件管理页面使用 npm 包名 `dsh-skill-detective` 安装 bundle 并启用。源码开发可安装本仓库的本地目录；单独执行全局 `npm install -g` 不会自动把插件接入当前 DSH 配置。
2. 打开「技能管理」，确认扫描到了已有技能。需要安装或整合技能时，在页面中明确选择「用于审查的会话」；该会话必须使用已经配置、可用的模型。
3. 回到需要使用的对话，勾选输入框工具栏的「🐟 技能侦探」。开关按会话保存，其他会话需要单独开启。
4. 正常发送任务请求。只有模型判断为未覆盖的需求时才会推荐；点击「帮我找」才开始检索、审查与安装。知识提问、已覆盖需求和已选择「先不用」的需求会保持静默。
5. 更新已安装的插件后，按 DSH 插件管理器的提示重载或重启，再刷新 Web 页面，避免前端与 Host 运行不同版本。

### 没看到推荐时

先检查当前会话开关、模型配置，以及设置页的「不再提示的需求」。模型不可用或判断超时也会跳过推荐，因此没有弹气泡并不等于没有执行判断。可在技能管理页手动检索；涉及模型审查的安装同样需要有效会话。

## 功能

- **对话内勾选**：输入框工具栏出现 `🐟 技能侦探`，默认关闭；勾选后，用户发消息时 Host 侧做语义分析。
- **大模型判断触发**：每条消息交给 Harness 的 `llm` 服务做一次小请求，判断「是不是任务」「已装技能能不能覆盖」。知识型提问（如「K8s 是什么东西啊」）不弹；`sqlite-query` 不会误判成覆盖「数据看板」；返回稳定的 `needKey` 供「先不用」和节流复用。不再维护关键词表与正则。
- **推荐气泡**：命中未覆盖的需求时浮出 380px 小气泡，提「帮我找」「先不用」。点「先不用」会按 `needKey` 写进**持久名单**，之后不再弹，可在「技能设置 → 不再提示的需求」里恢复。
- **五步执行**：语义分析 → 检索 skills.sh → 安全审查 → 下载 → 装载启用，全程在气泡内，不向对话流插入任何卡片。
- **大模型安全审查**：安装前获取候选技能目录内所有受支持的文本文件，判断数据外联、凭据读取、破坏性命令、混淆执行、供应链投毒与指令注入。模型输出必须满足完整 JSON 合约；`suspicious`、`malicious`、顶层或明细中的 `high` / `critical` 均拒绝安装。无法取得完整清单、内容校验失败、未知格式、链接或不可审查的二进制内容也会拒装。审查提示词见 `prompts/security-audit.md`；缓存同时绑定文件全文、路径、审查政策和提示词版本，读取时检查过期。
- **市场准入**：下载内容必须通过同一套大模型审查才会写盘；内置目录是随包发布的本地模板，安装时同样过审查。
- **技能索引文件**：安装/扫描时把每个技能的能力摘要、触发词、作用域、指纹写进 `$DSH_HOME/skill-detective/index.json`。之后每条消息只读这份索引，不再遍历技能根目录、不再解析每个 `SKILL.md`；只有安装、`skills/change`、面板刷新和手动扫描才重新落盘。
- **技能管理页**（左侧栏「技能管理」）：按来源分组（插件安装 / 市场安装 / 结构整合 / 本地扫描 / 用户自建）、搜索、筛选、统计、详情、打开文件位置、启用/禁用、删除。选择「用于审查的会话」后才能执行需要模型的安装与整合；不会猜测最近会话。同名技能通过实例 ID 区分工作区、作用域和临时会话。替代候选必须保持等价能力；Word、Markdown、HTML 等相关格式不会被自动当成彼此的替代。
- **同名冲突可选**：安装时遇到同名技能不再直接失败，面板和气泡会给出「覆盖安装 / 改名安装 / 取消」。覆盖会替换原目录；改名会保留原名作为显示名，目录用 `name-2` 之类的唯一名。
- **名称自动转写**：中文、大写或带空格的名称不再被拒绝。内部目录自动转成合法 ASCII slug（中文名优先采用模型建议的英文 slug），原名称保存在 `displayName` 里；面板显示原名并附小号 slug，点详情/操作仍指向真正安装的那个技能。
- **安装即扫描**：插件装载后自动扫描全部已登记工作区的 `<workspace>/.dsh/skills`、`$DSH_HOME/skills`、临时目录，以及 DSH 技能注册表里的**插件自带技能**。扫描保留同名的所有实例；会话判断只使用当前工作区及当前临时会话可用的实例。插件自带技能仅可查看，避免改写所属插件的文件。
- **插件技能折叠**：同一个插件包自带 5 个及以上技能时，管理页把它们收成一行，行首小三角展开/收起；搜索时自动展开命中项。
- **技能市场页**：内置 30 个技能（文档 / 数据 / 开发 / 网络 / 办公五类），首屏 12 张卡片，底部「加载更多」每批 12 张；搜索框过滤完整目录，旁边「联网搜索 skills.sh」走远程目录。
- **多源检索**：本地检索 → 内置目录；点「联网搜索」→ skills.sh 公共目录，下载走 GitHub raw，依次尝试 `raw.githubusercontent.com` → `ghproxy.net` → `cdn.jsdelivr.net`，任一可用即完成安装；三个镜像都不通时回退到 `api.github.com/contents`（base64），因此只放行 API、不放行 raw CDN 的网络也能安装。
- **检查更新**、**删除留痕**、**技能学习**、**技能设置**、**Agent 不可见的分层**等能力保持原有行为；学习和整合稿也会先过大模型安全审查。

## v1.5.0 改造

两处针对审查意见的加固，均带回归测试（`npm test` 运行完整测试集）：

### 每条消息不再随技能数量变慢

- 消息路径先用**本地索引预筛**：按技能名、显示名、`summary`、`capabilities`、`triggers`、描述做中英文 token 打分（CJK 二元组 + ASCII 词），只把最相关的 12 个技能写成详细条目。
- **其余技能以裸名称列表**出现在同一份提示里，模型仍可用 `coveredBy` 指认它们，不会因为旧版 `slice(0,150)` 而把第 151 个之后的技能完全藏起来（实测旧版 200 个技能时有 50 个对模型不可见）。
- 整个提示有 9,000 字符的硬预算，超出时先缩描述宽度，再缩名称尾巴，用户消息本身不缩。
- 消息路径以 `listInstalled(workspace, { scan: false })` 读索引：索引没建立时**跳过这一次推荐**，绝不在用户这一轮里走盘扫描；测试里把 `scanOnce`/`ensureScan` 换成会抛错的桩，验证整条路径从不触发扫描。
- 实测 200 个已装技能：典型摘要提示 12,177 → 3,846 字符（-68%），240 字长摘要 39,177 → 5,826 字符（-85%）。

### 安全审查不再能被截断/上限绕过

- 审查输入**按 48,000 字符分段**送给模型，超长文件按 `#partN/M` 切开，一个字节都不丢；不再有「超过 24,000 字符截断」「超出 120,000 预算不含内容」这类盲区。
- 分段结论按**最坏优先**合并（`malicious` > `suspicious` > `safe`，severity 取最高，findings 累积），单段失败即整单拒绝，`high`/`critical` 直接阻断安装。
- 段数超过 12 段、同目录文本文件超过 40 个、单文件超过 256KB、总量超过 512KB 时**拒绝安装**，而不是装一份只看了一部分的审查结果；同目录出现可直接运行的二进制文件（`exe`/`dll`/`so`/`node` 等）同样拒绝。
- 审查提示词补了「常见绕过手法」（字符串拼接、base64/hex、间接执行、构建脚本夹带、拆分载荷、伪造清白、超长填充）与「分段审查」说明；仍不依赖任何正则匹配风险，判断交给模型。
- 小目录保持**一次模型调用**的快路径，按内容哈希缓存，重复安装同一份内容秒过。

## 本地修复分支（2026-11-13，尚未发布）

- 安装先取得固定 Git 提交及完整目录清单，并用 Git blob 哈希验证镜像和 API 内容；清单缺失、被截断、文件下载失败或大小超限都不再退化为只审查 `SKILL.md`。
- 临时安装和作用域移动必须提供明确、有效的会话；注册失败会回滚，不会显示「已装载」。禁用、移除和移动会释放对应临时注册。
- 文件安装、覆盖和移动先写 staging，确认后再切换目录。失败恢复原目录与元数据；提交后清理失败保留操作成功结果并显示警告。
- 扫描与文件变更共享事务队列，避免旧扫描快照覆盖刚安装或移动的索引；事务内的首次懒扫描可重入，不会等待自身造成死锁。
- 操作接口接受 `instanceId` 和 `path`，只按名称无法确定唯一实例时返回冲突。显式无效工作区不会回退到默认目录。
- 状态、索引、缓存损坏时保留原文件并报告错误；写入保留 `.bak`，采用独立临时文件原子替换，同进程多个存储实例的更新会串行化。
- 页面进度仅展示真实服务端结果；网络、未找到、审查失败和会话注册失败分别显示。切换审查会话时，旧请求不会覆盖新会话的状态。
- 文档结构整合完整保留来源内容和代码块，质量分只描述文档结构。若来源带脚本或资源，仅允许预览，避免生成缺少配套文件的可启用技能；纯 Markdown 来源仍可审查后安装。
- 更新比较遵循版本顺序，不把旧目录版本当作升级；需求提示严格遵守字符预算，超长消息会跳过推荐而非截断用户意图。
- `npm test` 自动运行全部回归文件；CI 覆盖 Windows / Ubuntu 与 Node 22 / 24，发布工作流在打包、发布前先运行测试。

这些检查用于安装前风险筛查。模型误判、跨分段组合行为、后续下载依赖和实际执行权限仍有独立边界；本插件没有另建执行沙箱，也不能用测试通过率表示恶意技能检出率。

## 目录约定

| 作用域 | 真实位置 |
| --- | --- |
| 全局 | `$DSH_HOME/skills/<name>/SKILL.md`（默认 `~/.dsh`） |
| 工作区 | `<workspace>/.dsh/skills/<name>/SKILL.md` |
| 临时 | `$DSH_HOME/skill-detective/temp/<sessionId>/<name>/SKILL.md` |
| 插件自带 | `<插件包>/skills/<name>/SKILL.md`（扫描可见，只读，不参与安装/删除） |

默认作用域是**全局**：DSH 的 `skill-filesystem` provider 通过「最近的 `.git` 祖先」解析项目根，没有 `.git` 的工作区不会扫描 `<workspace>/.dsh/skills`，工作区作用域只对真正的仓库目录生效；全局目录对每个会话都生效，所以作为默认值更可靠。

禁用写入 SKILL.md frontmatter 的 `disable-model-invocation: true`，官方 skill provider 会据此不再让模型自动调用。

生成的 frontmatter 对 `@作者名`、含中文冒号的值统一加双引号，避免 YAML 把这些标量解析成映射或标签而导致整个技能被跳过。

## 数据与接口

- 状态文件：`$DSH_HOME/skill-detective.json`（按实例保存来源、版本、作用域、工作区/会话、安装时间与 `displayName`，以及不再提示名单、删除墓碑、会话勾选）。
- 索引文件：`$DSH_HOME/skill-detective/index.json`（v2 按 `instanceId` 保存技能名、能力摘要、触发词、作用域、工作区/会话、路径与指纹，兼容迁移 v1）。每条消息的触发判断只读这里。
- 审查缓存：`$DSH_HOME/skill-detective/audit-cache.json`（内容哈希 → 模型结论，最多 120 条、保留 180 天）。
- 浏览器半通过 `/api/dsh-skill-detective/*` 读写，路由仅接受同源请求；面板不做任何文件操作。
- 扫描接口：`POST /api/dsh-skill-detective/scan` 手动重扫（返回 `total` / `added` / `roots` / `workspaces`），`GET /api/dsh-skill-detective/state` 返回索引快照与合并后的 `installed` 列表。
- 安装接口的 `conflict` 可选 `overwrite` / `rename` / `cancel`；实际目标目录存在时必须确认，即使索引尚未收录。冲突响应包含目标的 `instanceId`、`path` 与建议改名，覆盖请求会校验目标实例。
- 调试接口：`POST /probe`、`POST /analyze` 返回当前大模型的触发判断（`actionable`、`needKey`、`coveredBy`、`suggestedSkill`）。

## 状态清理策略

状态文件的所有集合都有保留上限，写入时统一裁剪（`pruneState`）：

| 集合 | 保留策略 |
| --- | --- |
| `sessions` | 30 天未使用删除，最多 300 条 |
| `suppressed` | 用户显式选择，保留 365 天，最多 300 条 |
| `deleted` | 删除墓碑保留 30 天，最多 100 条 |
| `installs` | 最多 500 条，按安装时间淘汰最旧 |
| `discovered` | v1 旧快照一次性迁入索引后删除，不再写回状态文件 |
| `index.skills` | 30 天未再出现的本地记录删除，最多 2000 条 |

索引和审查缓存替换了原先只增不减的 `discovered` 快照，状态文件只保留小型偏好与元数据。

## 模型与速度

- 复用 Harness 已配置的 `llm` 服务，不需要额外 API Key；优先使用当前会话的默认模型，未配置时再选 `flash` / `lite` / `mini` / `chat` 这类非推理轻量型号。
- 触发判断约 200-400 输出 token，审查约 700 token，均带超时；需要明确的有效会话路由。超时或模型不可用时**不弹推荐**，审查则**拒绝安装**。
- 审查按技能目录内容哈希缓存，同一份内容只审一次；技能索引让每条消息的热路径只读一个小 JSON，不再扫盘。

## 检索说明

有网时先请求 skills.sh 搜索接口，命中结果只用于给候选补全安装量；接口不可用时如实标记来源为内置目录，不伪造远程结果。安装内容来自本插件的精选目录（30 个技能的真实 SKILL.md 模板，新增条目在 `catalog.js`）。

## 卸载

插件管理器卸载 bundle 后，已安装的技能目录仍在 `.dsh/skills` 下，可在「技能管理」页删除，或直接删除对应目录。
