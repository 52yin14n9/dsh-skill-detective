# 技能侦探 · Skill Detective

本插件由 CyberMind 的 52yin14n9、Admie、Assomeity、George 联合开发。

给 DeepSeek Harness 用的自动技能管家：在对话里发现缺失的技能，检索候选，安装前做安全审查，安装后统一管理。

## 功能

- **对话内勾选**：输入框工具栏出现 `🐟 技能侦探`，默认关闭；勾选后，用户发消息时 Host 侧做语义分析。
- **推荐气泡**：短语匹配到需求（爬虫 / Word / Excel / PPT / PDF / Git / SQLite）时，在输入框上方浮出 372px 的小气泡，提两个按钮：「帮我找」「先不用」。**已安装且启用**的技能覆盖同一需求时只出 2 秒轻提示，不打扰。
- **五步执行**：语义分析 → 检索 skills.sh → 安全审查 → 下载 → 装载启用，全程在气泡内，不向对话流插入任何卡片。
- **安装前安全审查**：扫描候选的 SKILL.md 与脚本代码，命中 `eval` / `atob` 混淆 / `new Function` / 子进程 / 未知外联域名即判定带毒，删除并继续下一个候选；候选全部带毒则显示「本鱼没发现好用的技能呢」。
- **技能管理页**（左侧栏「技能管理」）：按来源分组（插件安装 / 市场安装 / 用户自建）、搜索、筛选、统计、详情、打开文件位置、启用/禁用、删除。
- **技能市场页**：31 个常用技能（文档 / 数据 / 开发 / 网络 / 办公五类），首屏只渲染 12 张卡片，底部「加载更多（已显示 X / Y）」每批追加 12 张，加载完显示总数；搜索框在**完整目录**里过滤名称与描述，命中后从第一批重新开始。安装按钮走「审查中 → 安装中 → 已安装」，通过审查才写盘。
- **技能设置**：默认下载作用域（全局 / 工作区）、逐技能作用域（临时 / 工作区 / 全局）与工作区多选；保存即移动真实文件并生效。
- **Agent 不可见的分层**：临时作用域写入独立临时目录，并注册到当前会话的 skill scope，不进入全局 catalog。

## 目录约定

| 作用域 | 真实位置 |
| --- | --- |
| 全局 | `$DSH_HOME/skills/<name>/SKILL.md`（默认 `~/.dsh`） |
| 工作区 | `<workspace>/.dsh/skills/<name>/SKILL.md` |
| 临时 | `$DSH_HOME/skill-detective/temp/<sessionId>/<name>/SKILL.md` |

默认作用域是**全局**：DSH 的 `skill-filesystem` provider 通过「最近的 `.git` 祖先」解析项目根，没有 `.git` 的工作区不会扫描 `<workspace>/.dsh/skills`，工作区作用域只对真正的仓库目录生效；全局目录对每个会话都生效，所以作为默认值更可靠。

禁用写入 SKILL.md frontmatter 的 `disable-model-invocation: true`，官方 skill provider 会据此不再让模型自动调用。

生成的 frontmatter 对 `@作者名`、含中文冒号的值统一加双引号，避免 YAML 把这些标量解析成映射或标签而导致整个技能被跳过。

## 数据与接口

- 状态文件：`$DSH_HOME/skill-detective.json`（来源、版本、安装量、作用域、安装时间）。
- 浏览器半通过 `/api/dsh-skill-detective/*` 读写，路由仅接受同源请求；面板不做任何文件操作。

## 检索说明

有网时先请求 skills.sh 搜索接口，命中结果只用于给内置候选补全安装量；接口不可用时如实标记来源为内置目录，不伪造远程结果。安装内容来自本插件的精选目录（31 个技能的真实 SKILL.md 模板，新增条目在 `catalog.js`）。

## 卸载

插件管理器卸载 bundle 后，已安装的技能目录仍在 `.dsh/skills` 下，可在「技能管理」页删除，或直接删除对应目录。
