## 本轮发现并修复

| 问题 | 原行为 | 修复与验证 |
| --- | --- | --- |
| 一次安装成功后推荐停止 | 成功标记永久阻断轮询，直到组件重新挂载 | 移除永久锁；成功提示结束后可接收后续推荐，验证连续两次推荐各自保留会话 |
| 旧气泡误抑制新需求 | dismiss 仅传会话 ID，处理时读取该会话最新 pending | 每条推荐 UUID；只处理匹配的 ID，过期操作不影响新推荐；成功/已覆盖确认不写永久忽略 |
| 覆盖确认与重试失去目标 | 气泡重试未传原实例和作用域，默认配置变化可能改变覆盖对象 | 重试保留实例 ID、路径、作用域及会话，并验证网络失败后的再次重试 |
| 临时技能移出失败 | 目标非 temp 时客户端丢弃源会话 ID | 所有作用域移动都保留选定会话，供源临时实例定位 |
| 设置部分成功后无法重试 | 前面已移动的实例 ID 过期，后面失败后再次提交旧 ID | 记录已经完成的移动；即时重试跳过成功项；刷新后重建身份并保留未成功编辑 |
| 临时覆盖丢失真实注册 | 宿主同名 runtime 注册为 first-wins，先注册新项再释放旧项会删除实际赢家 | 先释放后注册；失败恢复旧载荷；测试 mock 改为真实 first-wins 语义 |
| 插件重载与会话恢复丢失临时注册管理 | 旧注册只归 agent context 所有，插件卸载不释放；新实例无法接管 | 同时由插件和 agent 生命周期释放，插件加载/agent 创建时恢复对应会话启用的临时技能 |
| 临时技能配套资源定位缺失 | 注册只有正文，缺少文档路径和资源目录 | 注册包含 runtime source、SKILL.md path、directory resourceBase |

| 发布标签版本不一致 | tag 与 package.version 不同也会尝试 npm publish | 发布前校验 tag 必须等于 v + package.version，避免重复发布旧版本 |
| 新用户安装说明缺失 | README 没有安装/开启顺序 | 增补 bundle 安装、选择审查会话、按会话开关、更新重载和无推荐排查说明 |

## 明天建议验收的流程

1. 开启会话中的技能侦探，对未覆盖任务选择「帮我找」；成功提示消失后，再发另一种任务，确认能继续收到推荐。
2. 让同会话产生两个先后需求，旧气泡的「先不用」不得把更新需求记入永久忽略。
3. 对存在的技能选择覆盖安装，模拟失败后点重试，确认目标实例/作用域保持原确认值。
4. 将某会话临时技能移到全局或工作区，确认能定位源实例；其他会话的同名临时技能不被改变。
5. 同时修改两个作用域，让第二项失败；修正后重试，不应再次提交已完成的旧实例 ID，未成功编辑不应丢失。
6. 临时安装后覆盖，再禁用/启用；检查实际会话技能目录，不只看管理页状态。
7. 重载插件或恢复会话，确认当前会话启用的临时技能恢复，禁用项和其他会话技能不会被恢复到当前会话。

真实模型安装依赖所选会话、模型服务与外部源可用性；上述隔离测试不替代使用本人配置做最终交互验收。

## 仍有边界与未实现功能

- **进程中断恢复未完成**：普通异常会回滚，但覆盖/移动目录切换途中强杀 Host，仍可能留下隐藏 stage/backup。需要独立的事务日志与启动恢复设计。本轮没有宣称 crash-safe。
- 临时注册依赖宿主 register-only API；如果新注册和恢复旧注册都被宿主持久拒绝，无法保证旧技能仍在线，错误会记录，磁盘/状态按现有机制回滚。
- LLM 审查仍有误判、跨分段组合行为识别与后续依赖下载边界，没有新增执行沙箱。
- 原痛点清单的全选、技能调用使用统计、拼音/模糊搜索、文件回收站没有在本轮伪装成已实现；删除留痕不等于可恢复的文件回收站。
- 英文 locale 按既有决定不做全面重写。
